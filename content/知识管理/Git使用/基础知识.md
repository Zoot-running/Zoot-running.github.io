# 1. 用户名与账户
Git 要求你配置用户名和邮箱，是为了在你每次提交（commit）代码或文件时，记录下是谁做出了这个修改。
**Git 配置的用户名 / 邮箱 vs. GitHub 用户名 / 邮箱**

**Git 本地配置 (`user.name`, `user.email`)**：
- 这是**本地**的配置，存储在你电脑的 Git 配置文件中（全局配置在 `~/.gitconfig`）。
- 它可以是任何你想要的名字和邮箱，**不一定**要和你的 GitHub 用户名或邮箱一致。
- 它的主要作用是**在提交记录中署名**。
**GitHub 账号**：
- 这是你在 GitHub 网站上注册的账号，有自己的用户名（`Username`）和邮箱。
- 当你执行 `git push` 将代码推送到 GitHub 时，GitHub 通过你本地 Git 配置的 `user.email` 来判断这个提交应该归属于哪个 GitHub 账号。

**最佳实践**：为了让 GitHub 能正确地将你的本地提交与你的 GitHub 账号关联起来，建议你在本地 Git 中配置的 `user.email` **使用你在 GitHub 账号中注册并验证过的邮箱**。这样，你的所有贡献才能被正确计数和显示。
