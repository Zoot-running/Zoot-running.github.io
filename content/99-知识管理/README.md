# 2. 博客
本地知识，包含还未完成的文档，都会公开在本站。
云端使用[github page](https://docs.github.com/zh/pages)作为博客页面，方便自己和大家随时查看。
静态页面由[Quartz 4](https://quartz.jzhao.xyz/)生成。

Obsidian把Quartz项目的本地文件夹content作为vault进行知识管理，可以做到一个仓库管理知识和项目。详见[[Obsidian 笔记同步至 GitHub Pages（Quartz 4 版）完整搭建方案]]
